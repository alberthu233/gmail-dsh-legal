Privacy Policy

Last updated: 2026-11-14

Gmail DSH (the app) is a personal, locally-run tool. This policy explains what data it accesses and how it is handled.

What the app accesses

With the mailbox owner explicit OAuth consent, the app uses the Gmail API to read messages and labels, and to modify labels or send replies when the owner asks it to. Scopes requested: gmail.modify and gmail.settings.basic.

Where data is stored

OAuth credentials are stored only on the owner computer, in the owner home directory, with file permissions restricted to that user. Message content is processed in memory on that computer. Optional local indexes, if enabled, stay on the same computer.

What is not done

The app does not operate a server, does not upload mail to a third-party service, does not sell or share data, and does not use mail content for advertising or model training.

Third parties

The app calls Google Gmail API directly. Google own privacy policy applies to that API traffic: policies.google.com/privacy.

Retention and deletion

Data lives only on the owner computer and can be deleted at any time by deleting the credential files. Access can be revoked at myaccount.google.com/permissions.
